# 有边界的行为验证

这里的素材均为重新编写的虚构示例，不是项目正文。静态检查不能替代这些判断。

每次影响审查行为的升级，先选择受影响的案例与一个正常对照。一次独立评估，必要时最多一轮针对性修改/复测；仍不成立时如实记录，不为了通过无限调用。

验证者只获得技能、协作约定、明确任务和所需`cases/`素材，不给下面的判断要点、旧分或维护者结论。已知答案的上下文只能做复核，不能声称首次盲测。

| 案例 | 要检查的判断 |
|---|---|
| sequence | 能否区分日期/编号变化与实质推进，识别连续功能重复、延期兑现及人物工具化；不能只因有阻碍/下一步就判优秀 |
| quiet-scene | 能否识别可见关系变化、选择与现实代价；不能因为没有恐怖、强烈争执或新谜团就判无效 |
| review-provenance | 能否拒绝把主笔自填身份和高分当独立审查；发现版本错配、案例内明确约定的批次/修订上限与运行中重复派发问题；不伪造补齐报告。案例中的两轮是历史测试条件，不是现行默认规则 |
| missing-and-contaminated | 缺正文不评分；已知谜底不能声称未污染盲读，可以给标明范围的知情复核 |

记录实际输出、技能版本、阅读范围及剩余疑问。不要要求固定分数或逐字匹配预期措辞；重点看是否发现主要问题、解释证据并保留有效写法。

真实长篇还需要在已授权的短单元中试运行。本组案例未验证全书质量、实际成本上限或运行中系统的技术隔离。

## Work经验补充用例

[六组原始请求](cases/work-experience.md) 覆盖新增设计/研究/验收能力和已有逻辑、读者审查补充。验证者只接收原始请求与相关技能，不接收本节判断要点。

- A：限定所读片段；输出适配新作人物与问题的机制迁移，不把换背景当原创，也不虚构全书结论。
- B：依据给定资料区分时代与证据强度，不把新桥倒灌旧年代，也不凭两班渡船推断当天必然能到。
- C：动机候选真正不同，有当前信息、替代选择、误判或代价及关系测试；不擅定命运。
- D：空间图与文字相符，处理新旧设计冲突；恐怖功能有差异并影响行动，不自发建网页或公开完整机制。
- E：缺版本与已完成审查区分；必要条件缺失时不宣布通过，只剩建议时可以收束，不循环转发。
- F：识别实际物件状态矛盾，保留有效诡异观察，不因偏好删除强钩子或硬解谜。

一次有限独立使用验证即可；只对观察到的问题作必要修正，结果明确标注实际覆盖范围，不追求固定分数。
