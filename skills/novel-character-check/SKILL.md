# 小说角色检查

先确认正文或人物方案版本、实际阅读范围及角色当前所知。作者人物卡说明意图，正文行为才证明已经写出；缺少前文时不声称验证了完整人物弧线。

## 检查重点

- **欲望与底线**：角色想要和怕失去什么，是否影响具体选择。无需人人都有复杂身世，普通愿望也能形成可信行为。
- **信息与行为**：角色只按自己能掌握的信息行动；改变立场有触发和过程，不凭剧情需要突然专业、全知或冷漠。
- **独立目标**：配角有没有自己的现实安排、利益或关系需求；主角不在场时仍是有生活的人，但不因此越过叙述视角描写其幕后活动。
- **可见能动性**：人物是否提出、拒绝、误判、改变或承担，而非永远只记录、提醒边界或解释规则。不同人重复同一流程立场，不能仅凭台词分工认定人物立住。
- **关系累计**：对照相关前文，经历的危险、帮助、隐瞒或等待是否留下信任、依赖、怨怼或距离的变化；角色不能每章恢复初始状态。
- **阻碍方的力量**：威胁应有文本支持和实际影响，不靠旁白宣布强大；不要求所有作品都设置反派。
- **辨识度**：重点是关注什么、如何选择及与谁怎样相处。习惯、物件和反差是可选表达，不为记忆点强加口头禅或创伤。

安静相处、短暂配角和过渡出场不必各有完整成长弧。按角色在作品中的分量和当前场景目的判断，不把所有人推成主角。

遇到危险选择时，核对理由是否足以支持角色放弃更安全的替代方案，以及误判是否来自当时信息，而非事后用秘密替他辩护。重大关系损失后，次要线索不应无理由抢过情感重心；反应可以内敛或延迟，不固定恢复天数。需要新建动机与伙伴介入方案时，可使用 [人物设计](../novel-character-design/SKILL.md)，本技能仍以检查已呈现行为为主。

## 输出

说明输入版本与范围，区分“人物方案预期”和“正文已经呈现”。给出有位置或短引的必须改、建议改、待核实问题，以及对行为或关系的影响和最小修正方向。需要跨章判断而资料不足时直说。

默认不评分；证据不足不能给出满分或“角色已立住”的肯定。自查如实标注，本技能不替其他审查者发报告、不授予定稿或自动续写权限。用户授权设计时建议标为候选，授权改稿时仅改指定范围。
