# 通用改稿模式

以下示例经过泛化，用来理解反馈适用范围，不是待复制的情节或任何作品的真实稿件。

| 现象 | 应解决的问题 | 适用边界 |
|---|---|---|
| 关键清单突然出现并驱动行动 | 补必要来源，让读者理解角色为何相信和使用 | 已在前文交代过时不重复交接手续 |
| 人还在门外，却断言室内看不见的动作 | 核对视线和知识来源 | 回顾叙述中的事后认识需有清楚时间层次 |
| 危险场面反复描述相同气味和呼喊 | 保留关键受阻、选择和后果 | 不把所有安静场景也改成短句或追逐 |
| 重要关系事件后角色毫无反应 | 检查情绪、关系和行动的连续影响 | 反应可以延迟或内敛，不必固定哭泣或追问 |
| 每次新线索都拍照、登记而后不再使用 | 查记录行为是否服务具体判断或人物塑造 | 不禁止必要记录，不能仅以记录次数算推进 |
| 每章查询新日期，依旧没有任何结果 | 比较连续场景功能，合并重复或改变行动策略 | 一次失败可以有效；须看其是否改变判断或选择 |
| 强调“真相以后揭晓”却不断增加前置手续 | 核查阶段承诺是否有局部兑现 | 允许保留终极谜底，不等于延迟所有收获 |

## 修正取舍

删除冗余优先于增加解释，补关键条件优先于扩建世界观。需要新增设计时标为候选并保持作者决定权。

明确反馈的适用对象：这一次的紧急场面需要压缩，不等于全书都须短促；这一个物件需要说明来源，不等于所有物件都须列属性；这段对话缺少人物选择，不等于每句必须制造冲突。

作者最新明确决定优先于旧反馈案例。发现决定与当前正文冲突时指出差异，不悄悄改写正文事实或宣布已统一。
