# 小说逻辑审查

目标是查明文本能否成立，不是替既有写法寻找通过理由。没有证据不硬挑问题，也不以“以后可能解释”掩盖当前缺失的必要条件。

## 确认审查范围

- 记录当前正文版本、实际读到的章节或段落，以及采用的最新明确设定。候选、计划和正文事实分开，不从技能模板导入剧情边界。
- 单章问题读取必要承接；时间累计、人物持续动机和伏笔推进需比较相关多章。缺少正文就说明不能验证跨章结论，摘要只能辅助定位。
- 区分作者真相、读者已知、当前角色已知和角色误判。作者设定可用于一致性检查，不能补充角色尚未获得的信息，也不能冒充盲读。

## 按相关性检查

1. **时间累计**：事件顺序、昼夜、年龄、日期跨度和失联时长是否一致；跨数周或数月后，工作、伤势、资源、关系和调查动机是否仍可信。
2. **空间现场**：位置、视线、距离、出入口、遮挡和危险变化是否支持行动。
3. **动机与替代方案**：角色当时为何这样做；明显更自然的办法为何未选；反复失败后是否合理调整策略，而非永久接受同一手续。
4. **信息与道具**：判断有来源，重要物件能连续追踪；补必要因果，不要求记录每次无关交接。
5. **世界规则**：已建立的能力、限制和代价有无临时取消或被候选设定覆盖。
6. **伏笔与承诺**：线索是否被无故否定、重复解释或长期搁置；阶段问题有无局部回答。终极谜底尚未揭开，不等于所有调查都可无结果。
7. **因果结果**：行动的反馈实际改变了什么。新日期、新编号、新申请或“下章再确认”本身不是实质推进；排除假设、关系变化、放弃路线或付出代价可以是推进。

不要把每章没有大反转判成漏洞。必要过渡、蓄势或情绪余波按其上下文功能判断；长线节奏风险注明所读范围，不假称审过全书。

## 从线索到可核对的行动

线索给出的是可调查方向、角色判断还是已证实结果，要分清。残缺地址可支持去问，不证明拍摄地点；人物觉得被托付，不证明另一个人确实有意托付。异常证据应保留可比对的稳定部分，不靠随时改写全部证据解除任何矛盾。

对疑似断点，只追踪影响理解的状态转换：物件由谁持有、可见哪一面、怎样进入下一动作；电话是提示、响铃、通话还是结束。能由上下文自然推知的省略不强制补手续；前后明确互斥的状态不能用“读者会脑补”掩盖。时间未定时用相对先后，不补造分钟数。

区分“已定内容相互矛盾”“当前行动必需的答案未定”“现实依据待核实”“可选优化”。秘密未揭晓不自动等于逻辑错误；只阻断依赖该缺口的判断。复核沿用已有问题的实际对象，说明已解决、仍待处理或新增冲突，不把旧问题无条件贴到新版本。

## 输出与边界

给出版本与范围、结论（未见实质漏洞／需修正／证据不足），然后按阻断、应修、建议、待核实列出具体位置或短引、问题影响和最小修正方向。“阻断”指当前单元的关键因果失效；“应修”是明确需处理的局部损伤。使用旧报告“必须改”时补明属于哪一种，不能把真实应修改称建议来过关；待核实也不自动等于阻断。保留健康悬疑，说明不需要解释的部分。

默认不打分。即使逻辑成立，也不代表好看、人物丰满或值得继续扩写；不能用逻辑分抵消阅读质量问题。方案审查注明“尚无正文验证”。

自查标为自查，不代写另一审查者的报告或通过结论；本报告不签发正式定稿、独立验收或续写权限。正文改版后结论不自动迁移。仅在授权时修改正文，不用新大设定兜底。

接到具体审查委托就返回实际分析，不能只转发同一个任务并宣布完成。确需委派时由已授权主控收口、核对实际返回；本技能不自行建立循环消息链。
