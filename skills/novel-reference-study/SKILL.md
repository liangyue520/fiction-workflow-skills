# 小说参考研读

把参考作品转成当前创作可选择的方法。交付重点是“为什么有效、何时适用、代价是什么”，不是复述剧情或替作者决定设定。

## 先确定要解决的问题

以用户当前问题和已有正文为准，如入局动机不足、调查没有推进、熟人反常缺少情感基础、景别单一或阶段回报落空。接续已有故事时，先读承接点，分清已经发生、尚未确认与作者暂不公开的内容。

优先查已有索引与研读记录，再定向读取相关场景。按问题选择材料，不以遍读书库为前置条件，也不固定书目、卡片数量或章节配额。某本书不可读时说明缺口，用可读材料完成能支持的部分。

## 让结论受阅读范围约束

- 写明作品、作者、版本或来源、实际读取的章节与位置。区分本轮读过的原文、沿用的旧报告、出版方简介和他人解读。
- 目录定位、关键词命中、章首章末抽样不等于整章或全书精读。没有读到的回收段，不能判定伏笔已经兑现或永远未兑现。
- 先辨认正文边界：重复目录、附加猜测、番外和排版粘连可能改变事件定位。需要转码时保留原稿，并让引用位置可回查。
- 简介只能支持其明确提供的职业、委托或人物关系等信息，不能据此补出完整情节。人物自称明白、正文向读者展示答案、后附解读给出猜测，是不同证据。

每条分析分清：原作实际事件、人物当时的判断、研究者解释、拟用于新作的候选。解释不是作者意图的已证事实，迁移方案也不是当前小说已定设定。

## 提炼可用机制

只分析与当前问题有关的机制，沿“条件 → 选择或观察 → 行动 → 反馈与后果”追问。下列是观察入口，不是每张卡都要填写的表格：

| 问题 | 重点观察 | 迁移时的条件与代价 |
|---|---|---|
| 普通人为什么入局 | 现实收益、压力与本人选择怎样共同作用；旧线索何时成为机会 | 不能让一个神秘物件直接替代生活动机；主动选择也要保留犹豫、拒绝与失误的可能 |
| 旧线索怎样继续推进 | 同一物件如何改变用途；无法带走的发现如何转为可保留、可核对的证据 | 物件与信息的取得须成立；没有新判断、行动或后果的重复查看不算推进 |
| 熟人反常为什么有效 | 先前相处形成了什么预期，哪个可见选择打破预期，主角先误解了什么 | 先让关系在合作、补位或分歧中成立；反常行为本身不能证明秘密身份 |
| 解谜怎样成为行动 | 人物把判断拿去怎样验证；失败增加了什么信息，谁承担了代价 | 失败应改变认识或处境，避免同一办法原样重试；专业能力和伙伴各有局限 |
| 段落为什么有镜头感 | 视线从哪里到哪里，声音或动作如何改变注意，细节何时被看清 | 景别随观察目的、距离与遮挡变化；可先建立空间再收紧细节，但不机械轮换远中近景，也不越出叙述视角 |
| 单元为什么有回报 | 钱、经验、伤势、人脉、关系和答案中哪些实际留下，并成为下一段条件 | 分别检查人物关系的结果与承诺谜题的回答；“主角懂了”不能替代读者获得足够解释 |

讨论快慢时，比较相邻场景结束前后的处境。重复等待可压缩；告别、恢复和生活戏若改变人物理解、关系或下一步选择，应保留其分量。不把“有推进”简化成每章新增谜底、事故或赶路，也不为了快进跳过消息来源和行动因果。

## 迁移而非搬运

先用不带原作专名的句子概括功能与因果，再用新作人物的经历、利益、能力和场所条件重新成立。更换姓名、地点和物件外观，仍保留独特关系组合、关键场面次序或同一谜底的，不算完成迁移。

检查相似处叠加：若物件外形已经相近，就尤其警惕再借其能力、身世和揭谜顺序。可以只取人物行为组织、观察方式或线索验证方法，并明确不适用的部分。推荐时同时说明它解决哪个问题、要补哪些条件、会牺牲或挤压什么。

作者采纳某个方法后，按最新决定收窄建议；未采纳方案保留为参考，不继续混入当前安排。只被委托研究时，不自行改正文、公共设定或确定幕后真相。

## 交付

用能直接比较的短卡或短表呈现：当前问题、原作依据与阅读范围、机制、适用条件与代价、原创迁移候选。最后给出有理由的优先选择、仍缺的证据及需要作者决定的关键差异。

结论强度与证据相称：抽样研读可支持所读场景的方法分析，不能证明全书质量，也不能证明迁移方法已在新作生效。实际试写和阅读反馈尚未发生时，明确保留这一限制。
